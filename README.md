# ApuntaFácil OCR 📚

ApuntaFácil OCR es un proyecto diseñado para facilitar el estudio mediante la digitalización de apuntes a partir de fotografías.

## 🎯 Objetivo

Ayudar a estudiantes y opositores a ahorrar tiempo y organizar mejor sus materiales de estudio.

## ✨ Funcionalidades previstas

* 📷 Seleccionar fotos de apuntes.
* 🔎 Extraer texto mediante tecnología OCR.
* 📝 Facilitar la lectura y el estudio del contenido.
* 📱 Acceder a la aplicación desde el móvil o el ordenador.

## 👨‍🎓 Público objetivo

Estudiantes, opositores y cualquier persona que quiera organizar sus apuntes de forma más cómoda.

## 🚀 Estado del proyecto

ApuntaFácil OCR está en desarrollo. Las funcionalidades disponibles dependen de la versión publicada.

## 💡 Nuestra visión

Hacer que estudiar sea más sencillo, práctico y accesible.
